Стандарт доступа Zero Trust

Статус: active. Владелец: команда Security. Код стандарта: ZTA-17.

Доступ к инженерным сервисам

Для доступа к Qdrant, GitHub Actions и средам customer-data сотруднику нужны корпоративный SSO, аппаратный ключ FIDO2 и активная проверка устройства.

VPN

VPN является резервным каналом только для аварийного доступа. Постоянное использование VPN вместо Zero Trust запрещено.
